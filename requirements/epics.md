# Epics — Todo List App

Grouping of the 6 user stories (see `user-stories.md`) into epics for planning purposes.

---

## Epic 1: Task Management
**Goal:** Let the user create and maintain the contents of their task list.

**Stories:**
- US-1: Add a task
- US-3: Mark a task complete or incomplete
- US-4: Delete a task

---

## Epic 2: Task Visibility
**Goal:** Let the user see and focus on the right subset of their tasks.

**Stories:**
- US-2: View my tasks
- US-5: Filter tasks by status

---

## Epic 3: Data Persistence
**Goal:** Ensure the user's list survives beyond a single browser session.

**Stories:**
- US-6: Persist data across sessions

---

## Summary Table

| Epic | Goal | Stories |
|---|---|---|
| Task Management | Create and maintain task list contents | US-1, US-3, US-4 |
| Task Visibility | See and focus on the right subset of tasks | US-2, US-5 |
| Data Persistence | Ensure the list survives beyond a session | US-6 |
